# Labratory-supply-tracker-

How to Run: 

1. Open the project folder in Spyder.
2. Run main.py
3. Use the numbered menu to manage lab supplies across locations and load sample data when needed.

 Menu Choices: 
1. Store and search supplies (by item or location)
2. Issue or receive stock at a location
3. Transfer stock between two different locations
4. Low-stock and restocking cost report for a selected location
5. Save records to a local file
6. Load records from a local file
7. Exit


How to Test: 
- Test valid inputs for each menu option.
- Test invalid inputs (such as negative quantities, duplicate IDs, unknown items/locations, or transferring between the same location) and verify records do not change.
- Test exact boundary values, empty records, and a missing save file.
